# ADR 0001: Full canonical architecture is the delivery target

Date: 9 September 2026

Status: Accepted by explicit user instruction in the project conversation.

## Problem

The first execution plan proposed a smaller Saturday subset. The user explicitly
requested the full architecture instead of a silently reduced project.

## Decision

Build the entire canonical 9 September architecture. All stages, eight fictional
documents, nine representative published profiles, all bounded workers, and the
canonical evaluation and release gates remain targets. Build and verify incremental
vertical slices without treating a slice as the completed product.

The original canonical content boundary also remains: all 63 journey records exist,
but only appropriately reviewed content is published. This does not require inventing
54 unique weekly medical guides. Videos/MCP and other canonically deferred tools
are not reintroduced by the full-scope decision.

## Consequences

The smaller Saturday proposal is withdrawn. Saturday remains a target; actual
unfinished scope must be reported rather than hidden. Effort estimates stay visible
and will be recalibrated against measured implementation and review progress.
No safety, isolation, provenance, confirmation or evaluation gate is displaced.

Kajal owns product/UI/evaluation, Codex leads technical implementation, and Aswath
coordinates access, tradeoffs and team acceptance. External clinical review is not
replaced by engineering tests.
